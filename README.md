# Adventure Game

This is a simple texted-based Python adventure game created as part of my Engineering coursework. 

## Features

-Asks the. player their name 
-Lets the player choose between a forest or a cave path
-Uses functions to organize the game    
-Uses if/else conditionals to handle choices 
-Uses a loop to allow the player to restart the game
-Uses a '.lower()' to handle different capitalization in user input 

## Functions 
- 'start_game()' - starts the game and asks the player to choose a path
- 'forest_path()' - handles the forest scenario
- 'cave_path()' - handles the cave scenario
